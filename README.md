# Arkhime extension stores

Extension store indexes for the Arkhime app. Add a link in Arkhime under
Settings → Extensions → (Manga or Anime) → Add repository.

| Type  | Link |
|-------|------|
| Manga | `https://raw.githubusercontent.com/Arkhins-0/Arkhime/repo/manga/index.pb` |
| Anime | `https://raw.githubusercontent.com/Arkhins-0/Arkhime/repo/anime/index.pb` |

Each folder also has the same data as `index.json`.

The extensions themselves are not hosted here. Each entry points at the upstream APK:

- Manga: [Keiyoushi](https://github.com/keiyoushi/extensions) (extension lib 1.6)
- Anime: [Yuzono](https://github.com/yuzono/anime-repo) (extension lib 14)

The versions are a snapshot taken when this branch was last updated.
